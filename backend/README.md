# Backend — UniBite

Aquí irá la API web y la lógica de negocio. El lenguaje/framework aún está pendiente.

Módulos propuestos por dominio: `auth`, `usuarios`, `emprendimientos`, `publicaciones`, `solicitudes`, `pedidos`, `entregas` y `administracion`.

Cada módulo podrá contener controladores, servicios, validaciones y acceso a datos según el framework elegido. El frontend debe comunicarse con el backend a través de la API, no con PostgreSQL directamente.
