# Reglas de negocio acordadas — UniBite

1. **Publicación:** cada oferta indica alimento, precio, cantidad máxima, fecha/hora y lugar de entrega, y hora límite para recibir solicitudes. La cantidad límite no tiene que mostrarse al comprador.
2. **Solicitud:** antes del cierre, un comprador solicita una cantidad.
3. **Respuesta:** el emprendedor puede aceptar toda la cantidad, proponer una cantidad menor o rechazar la solicitud.
4. **Confirmación:** la aceptación completa confirma el pedido; si hay contrapropuesta, se confirma cuando el comprador la acepta.
5. **Cantidad en contrapropuesta:** el comprador puede aceptar menos unidades que las ofrecidas; la diferencia vuelve a estar disponible.
6. **Cierre de recepción:** al llegar la hora límite, no se admiten solicitudes nuevas. Las recibidas antes del cierre sí pueden continuar resolviéndose.
7. **Pendientes tras el cierre:** el emprendedor puede resolver solicitudes previas al cierre, y las contrapropuestas ya enviadas pueden quedar a la espera de respuesta. Se contempla un límite horario posterior para cerrar pendientes, pendiente de parametrizar formalmente.
8. **Reserva:** un pedido confirmado queda reservado sin depender del pago.
9. **Pagos:** se acuerdan externamente por WhatsApp (efectivo a la entrega o transferencia anticipada); la plataforma no cobra, factura ni verifica bancos. El emprendedor puede registrar manualmente la modalidad acordada y marcar un pago como recibido.
10. **Entrega:** se ha acordado utilizar un código proporcionado por el comprador e introducido por el emprendedor para registrar la entrega. Este código no acredita el pago.

> El detalle de las ventanas horarias y cancelaciones debe quedar cerrado antes de implementarlo.
