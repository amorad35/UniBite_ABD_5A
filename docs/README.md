# Documentación académica — UniBite

- `01-propuesta/`: descripción, justificación y presentación.
- `02-requisitos/`: alcance, reglas de negocio y futuros casos de uso.
- `03-diseno/`: arquitectura, ER, diagramas y mockups.
- `04-pruebas/`: planes, casos y resultados de pruebas.
- `05-evidencias/`: capturas de implementación o actividad académica.
- `06-entregas/`: versiones finales de documentos que solicite el docente.

Preferir archivos editables y documentar la fecha/versión de cada entrega. Evitar introducir archivos pesados sin necesidad.
