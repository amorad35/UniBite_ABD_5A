# Frontend — UniBite

Aquí se desarrollará la interfaz web. La elección de framework está pendiente.

- `public/`: archivos públicos estáticos.
- `src/assets/`: recursos usados por el código.
- `src/components/`: componentes reutilizables (botones, tarjetas, formularios).
- `src/layouts/`: estructura visual compartida.
- `src/pages/auth/`: acceso y registro.
- `src/pages/comprador/`: catálogo, solicitudes y pedidos.
- `src/pages/emprendedor/`: publicaciones y gestión de solicitudes.
- `src/pages/admin/`: vistas administrativas.
- `src/routes/`: rutas y control de navegación.
- `src/services/`: llamadas a la API del backend (no a PostgreSQL directamente).
- `src/styles/`: estilos compartidos.

Cuando se seleccione tecnología se agregarán sus archivos reales (`package.json`, etc.).
